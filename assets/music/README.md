# Flush Funk

Original soundtrack generated locally with ACE-Step v1.5 Turbo for Shit-Tacular.
Seed: `112905`. Prompt and generation settings: `tools/generate_flush_funk.py`.

The game asset is stereo 48 kHz, 16-bit PCM, with a 40 ms crossfade joining the
end to the beginning. Godot loops it at -20 dB across menus and gameplay.
Press M to pause or resume music. Sound effects remain independent.
